# نبض النصر: بوت أخبار النصر على X

بوت يتابع أخبار **نادي النصر** و**كريستيانو رونالدو** و**جواو فيليكس** و**ساديو ماني** و**كينغسلي كومان**. يجمع الأخبار من المصادر الرسمية والإعلام الموثوق كل 15 دقيقة، ويعيد صياغتها بالعربي باستخدام Claude، ويرفق صورة الخبر إذا توفرت، ويجهزها لك مسودة. توافق عليها بضغطة من جوالك، فتنزل على حسابك في X وتظهر في صفحة أخبار مباشرة.

## كيف يشتغل

```
كل 15 دقيقة (GitHub Actions)
  │
  ├─ يبحث في Bing News و Google News + أي RSS رسمي تضيفه
  ├─ يقبل فقط المواقع اللي في القائمة (رسمية أو موثوقة) ويتجاهل الباقي
  ├─ يفتح الخبر ويقرأ نصه وصورته
  ├─ Claude يتأكد إنه خبر يخص النصر فعلًا، وإنه مو مكرر، ويعيد صياغته
  └─ ينشئ مسودة (GitHub Issue) فيها: نص التغريدة + الصورة + المصدر
        │
        ▼
  أنت تراجع من تطبيق GitHub في جوالك
  ├─ ✅ تضيف وسم approved  (أو تعلّق /publish)  → ينشر على X خلال دقيقة
  ├─ ✏️ تعدّل النص قبل الموافقة إذا تبي
  └─ ❌ تغلق المسودة إذا ما تبيها
        │
        ▼
  الخبر المنشور ينضاف لصفحة «نبض النصر» (GitHub Pages) وتتحدث تلقائيًا
```

## التجهيز خطوة بخطوة

### ١. ارفع المشروع على GitHub
1. سوّ حساب في [github.com](https://github.com) إذا ما عندك.
2. أنشئ مستودع جديد (New repository) باسم مثل `alnassr-news`. يقدر يكون **Private**.
3. ارفع ملفات هذا المجلد كلها، ومنها مجلد `.github` المخفي.

### ٢. مفتاح Claude لإعادة الصياغة
1. ادخل [console.anthropic.com](https://console.anthropic.com) وسوّ حساب.
2. من **Billing** اشحن رصيد (يكفي 10 دولار للبداية).
3. من **API Keys** اضغط **Create Key** وانسخ المفتاح.

> بدون هذا المفتاح البوت يشتغل، لكنه يحط العنوان الأصلي بدون إعادة صياغة ولا يقدر يتأكد من التكرار.

### ٣. مفاتيح X للنشر
1. ادخل [developer.x.com](https://developer.x.com) بنفس الحساب اللي تبي تنشر منه.
2. أنشئ **Project** و **App**.
3. في إعدادات التطبيق افتح **User authentication settings**:
   - App permissions: **Read and write**
   - Type of App: **Web App, Automated App or Bot**
   - Callback URL و Website: حط رابط حسابك، مثل `https://x.com/اسم_حسابك`
4. من **Keys and tokens** انسخ:
   - **API Key** و **API Key Secret**
   - **Access Token** و **Access Token Secret**. ولّدها **بعد** ما تخلي الصلاحية Read and write، وإلا بيفشل النشر.
5. X صارت تحاسب بنظام الدفع حسب الاستخدام، فاشحن رصيد من **Developer Console**.

### ٤. أضف المفاتيح للمستودع
في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**، وأضف:

| الاسم | القيمة |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاح Claude |
| `X_API_KEY` | API Key |
| `X_API_SECRET` | API Key Secret |
| `X_ACCESS_TOKEN` | Access Token |
| `X_ACCESS_TOKEN_SECRET` | Access Token Secret |

### ٥. شغّل صفحة الأخبار
**Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / المجلد `/docs` ← Save**

بعد دقيقة تصير الصفحة على: `https://اسمك.github.io/alnassr-news/`

> إذا كان المستودع Private وحسابك مجاني، GitHub Pages ما يشتغل. خلّ المستودع Public (المفاتيح تبقى سرية في Secrets) أو استخدم GitHub Pro.

### ٦. أول تشغيل
**Actions ← جمع الأخبار ← Run workflow**

بعد دقيقتين تقريبًا تلقى المسودات في تبويب **Issues**. وبعدها يشتغل البوت تلقائيًا كل 15 دقيقة.

### ٧. المراجعة من الجوال
نزّل تطبيق **GitHub** وفعّل الإشعارات للمستودع. كل مسودة توصلك إشعار:
- **للنشر:** افتح المسودة ← Labels ← `approved`، أو اكتب تعليق `/publish`.
- **للتعديل:** حرّر نص المسودة (Edit) بين العلامتين `tweet:start` و `tweet:end`، وبعدين وافق.
- **لحذف الصورة:** امسح الرابط بين `image:start` و `image:end`.
- **للرفض:** Close issue.

إذا فشل النشر، البوت يكتب لك السبب في تعليق ويحط وسم `publish-failed`.

## المصادر

| المصدر | كيف يتابعه البوت |
|---|---|
| الجهات الرسمية (النادي، الرابطة، الاتحادات، واس…) | بحث الأخبار + قائمة `official_domains` |
| صحيفة **الرياضية** (arriyadiyah.com) | بحث مخصص داخل موقعها (`site:arriyadiyah.com`) |
| صحيفة **الشرق الأوسط** (aawsat.com) | بحث مخصص داخل موقعها (`site:aawsat.com`) |
| صحيفة **ماركا** الإسبانية (marca.com) | بحث بالإسباني داخل موقعها، وClaude يترجم الخبر ويعيد صياغته بالعربي |
| حساب **سعد السبيعي** على X ‏(@saadlegal2030) | يقرأ تغريداته الجديدة كل دورة عبر X API |
| باقي الإعلام الموثوق | قائمة `trusted_domains` |

**عن تغريدات سعد السبيعي:**
- البوت يقرأ التغريدات الجديدة بس (بدون الردود وإعادة التغريد)، وClaude يتجاهل الرأي والنقاش ويأخذ المعلومات الإخبارية فقط.
- الخبر يُنسب له بالاسم («بحسب سعد السبيعي…»)، ويظهر في المسودة بوسم `x-account`.
- ينشر الخبر **كاقتباس** لتغريدته الأصلية، فيظهر مصدره وصورته تحت تغريدتك. إذا تبي تغريدة مستقلة غيّر `quote: false`.
- يحتاج مفاتيح X، وX تحاسب على كل تغريدة يقرأها.
- لإضافة حساب ثاني، أضفه تحت `x_accounts` في `config.yaml` بنفس الشكل.

## الإعدادات (`config.yaml`)

| الإعداد | وش يسوي |
|---|---|
| `auto_publish` | `true` ينشر مباشرة بدون مراجعة |
| `source_mode` | `official_only` الجهات الرسمية فقط، أو `official_and_trusted` الرسمية مع الإعلام الموثوق |
| `official_domains` / `trusted_domains` | قائمة المواقع المسموحة. أي موقع غيرها يتجاهله البوت |
| `extra_feeds` | روابط RSS رسمية تضيفها بنفسك |
| `include_link` | يحط رابط الخبر في التغريدة (X تحاسب عليه أغلى بكثير) |
| `hashtags` | الوسوم اللي تنضاف لكل تغريدة |
| `subjects` | اللاعبين والكلمات المفتاحية. تقدر تضيف لاعب جديد هنا |
| `claude_model` / `claude_effort` | نموذج Claude ومستوى التفكير |
| `max_age_hours` / `max_items_per_run` | عمر الخبر الأقصى، وعدد الأخبار في كل دورة |

## التكلفة التقريبية

| البند | التكلفة |
|---|---|
| GitHub Actions + Pages | مجاني، ضمن حدود الخطة المجانية |
| Claude (إعادة الصياغة) | حوالي 2 إلى 3 سنت لكل خبر يعالجه. لو عالج 20 خبر يوميًا تكون تقريبًا 12 إلى 18 دولار شهريًا |
| X (النشر) | حوالي 1.5 سنت لكل تغريدة بدون رابط |
| X (قراءة حساب سعد السبيعي) | حوالي نص سنت لكل تغريدة يقرأها. ولأن كل تغريدة جديدة تمر على Claude، لو غرّد 30 مرة باليوم تزيد التكلفة تقريبًا 20 إلى 25 دولار شهريًا. لتقليلها خلّ `require_keywords: true` عشان ما يعالج إلا التغريدات اللي تذكر النصر أو اللاعبين بالاسم |

لتقليل تكلفة Claude غيّر `claude_model` إلى `claude-sonnet-5-5`، فتصير التكلفة تقريبًا النص.


## ملاحظات مهمة
- **الصور:** صور الأخبار ملك أصحابها. البوت يذكر المصدر في كل تغريدة، لكن إذا وصلك اعتراض على صورة احذفها من المسودة قبل النشر، أو خلّ البوت يعتمد على المصادر الرسمية فقط.
- **الدقة:** Claude مقيد بأن يكتب فقط الموجود في المصدر، ويبدأ الأخبار غير المؤكدة بكلمة «تقارير:». ومع ذلك المراجعة قبل النشر هي صمام الأمان، فاقرأ المسودة قبل الموافقة.
- **توقيت GitHub:** التشغيل المجدول ممكن يتأخر 5 إلى 15 دقيقة وقت الزحمة. وإذا ما صار أي نشاط في المستودع 60 يوم يتوقف الجدول تلقائيًا، لكن تحديثات البوت نفسها تمنع هذا.
